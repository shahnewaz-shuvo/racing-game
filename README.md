# racing-game

A lightweight arcade racing game that runs in any modern browser.

## Play locally

1. Open `index.html` directly in your browser, **or**
2. Run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- `←` / `→`: steer
- `↑`: speed up
- `↓`: slow down
- `Restart Race`: restart after crashing

## Goal

Avoid incoming traffic as long as possible and beat your high score.


## Instant play file

Open `play.html` directly from your cloned GitHub repository to play immediately (no server required).
