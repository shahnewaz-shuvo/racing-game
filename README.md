# racing-game

A lightweight arcade racing game that runs in any modern browser.

## Play locally

1. Open `index.html` directly in your browser, **or**
2. Run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- `←` / `A`: steer left
- `→` / `D`: steer right
- `↑` / `W`: speed up
- `↓` / `S`: slow down
- `Space`: shoot (limited ammo)
- `Restart Race`: restart after crashing

## Features

- Car selection: Porsche, BMW, Mazda
- 3 game modes: Classic, Time Attack, Elimination
- Difficulty selection: Easy, Normal, Hard
- Bonus pickups for score and ammo
- Armored traffic cars that cannot be destroyed
- Traffic-light roadside visuals and retro arcade sound effects

## Instant play file

Open `play.html` directly from your cloned GitHub repository to play immediately (no server required).
